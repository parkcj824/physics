## Verified records

1. **Neural Operator: Learning Maps Between Function Spaces with Applications to PDEs.** Nikola Kovachki, Zongyi Li, Burigede Liu, Kamyar Azizzadenesheli, Kaushik Bhattacharya, Andrew Stuart, Anima Anandkumar; 2023; JMLR, volume 24, article 89 (as cited in the official README). [Paper link supplied by authors](https://arxiv.org/abs/2108.08481); [verified official source](https://github.com/neuraloperator/neuraloperator). Retrieved `neuraloperator.txt` and `fno_spectral_code.txt`. The code explicitly applies real FFT, a learned mode/channel contraction, and inverse FFT: `F^-1(R_theta(k) F(v)(k))`. C006 instead constrains a scalar physical-eigenvalue multiplier to `sum w exp(-tau lambda)` and receives the full physical eigensystem. This restriction is not proof of novelty. The original FNO paper (arXiv 2010.08895) was **not read** here.
2. **Learning nonlinear operators via DeepONet based on the universal approximation theorem of operators.** Lu Lu, Pengzhan Jin, Guofei Pang, Zhongqiang Zhang, George Em Karniadakis; 2021; Nature Machine Intelligence 3, 218–229. [DOI](https://doi.org/10.1038/s42256-021-00302-5); [verified author source](https://github.com/lululxvi/deeponet). Exact title/authors/venue/DOI are in the retrieved README. `G(u)(y)=sum_k b_k(u)t_k(y)` is a **background-knowledge formula**, not an equation verified in this fetched README. C003/C006 also produce basis/response expansions, so basis factorization alone is not an invention. Full text unreviewed.
3. **Physics-informed neural networks: A deep learning framework for solving forward and inverse problems involving nonlinear partial differential equations.** Maziar Raissi, Paris Perdikaris, George E. Karniadakis; 2019; Journal of Computational Physics 378, 686–707. [Publisher link from author source](https://www.sciencedirect.com/science/article/pii/S0021999118307125); [verified source](https://github.com/maziarraissi/PINNs). Metadata verified from README; `L=L_data+L_PDE+L_BC` is a provisional high-level summary, not a fully checked paper equation. This session uses direct supervised labels and residual checks rather than claiming a new PINN loss. Full text unreviewed.
4. **Hamiltonian Neural Networks.** Sam Greydanus, Misko Dzamba, Jason Yosinski; 2019. [Author-linked paper](https://arxiv.org/abs/1906.01563); [verified source](https://github.com/greydanus/hamiltonian-nn). Title/authors/year verified; venue **not verified in retrieved README**. The fetched `hnn.py` explicitly computes automatic gradients and multiplies by a canonical skew tensor (`J grad H`); the code also supports a gradient component. This directly establishes that the earlier oscillator setup baseline is not an invention and that differentiating a learned energy alone is insufficient novelty. Paper full text unreviewed.
5. **Lagrangian Neural Networks.** Miles Cranmer, Sam Greydanus, Stephan Hoyer, Peter Battaglia, David Spergel, Shirley Ho. [Author-linked preprint 2003.04630](https://arxiv.org/abs/2003.04630); [verified source](https://github.com/MilesCranmer/lagrangian_nns). Author/title and Euler–Lagrange code verified from README; 2020 is the preprint year, publication venue not independently verified here. The displayed implementation uses `qddot=(d²L/dqdot²)^+ [dL/dq-(d²L/dqdot dq)qdot]`. C003 is a static restricted action, not this dynamics model, but deriving equations from variational principles is not new by itself. Paper full text unreviewed.
6. **Learning to Simulate Complex Physics with Graph Networks.** Alvaro Sanchez-Gonzalez, Jonathan Godwin, Tobias Pfaff, Rex Ying, Jure Leskovec, Peter W. Battaglia; 2020; ICML. [Author-linked paper](https://arxiv.org/abs/2002.09405); [verified official source](https://github.com/google-deepmind/deepmind-research/tree/master/learning_to_simulate). Citation and implementation verified. `graph_network_code.txt` implements encoded graph processing with sum reduction. C002/C007 pairwise aggregation overlaps this broad computational family; explicit conservation is an additional constraint, not enough novelty. Paper full text unreviewed.
7. **Learning Mesh-Based Simulation with Graph Networks.** Tobias Pfaff, Meire Fortunato, Alvaro Sanchez-Gonzalez, Peter W. Battaglia; 2021; ICLR. [Author-linked paper](https://arxiv.org/abs/2010.03409); [verified official source](https://github.com/google-deepmind/deepmind-research/tree/master/meshgraphnets). README citation and `core_model.py` checked: `e'=MLP([v_sender,v_receiver,e])`, `v'=MLP([v,sum_received e'])`, with residual updates. New names for transfers are not a distinction from message passing. Paper full text unreviewed.
8. **pyMOR - Generic Algorithms and Interfaces for Model Order Reduction.** R. Milk, S. Rave, F. Schindler; 2016; SIAM Journal on Scientific Computing 38(5), S194–S216. [DOI cited by official source](https://epubs.siam.org/doi/10.1137/15M1026614); [verified source](https://github.com/pymor/pymor). README confirms reduced bases, POD and neural methods. 9. **PyAMG: Algebraic Multigrid Solvers in Python.** Nathan Bell, Luke N. Olson, Jacob Schroder, Ben Southworth; 2023; JOSS 8(87), 5495. [DOI](https://doi.org/10.21105/joss.05495); [verified source](https://github.com/pyamg/pyamg). Metadata and classical AMG scope verified. C002R is one-level Richardson, not multigrid; adding coarse relaxation would require comparison rather than a new name. Full paper unreviewed.
10. **e3nn official Euclidean neural-network library.** [Verified source](https://github.com/e3nn/e3nn). README verifies E(3) irreducible representations, tensor products and spherical harmonics. No paper citation/author/year/venue was verified, so none is invented. This is implementation-level evidence only. None of the current geometry handling establishes E(3)-equivariant learned architecture novelty.

## Equation-level disqualification

C001R is a direct classical Green formula. C002R is Richardson. C003 is Ritz/Galerkin. C004 overlaps exponentiated-gradient positive-state motion. C005 is an exponential-generator composition with a nonzero commutator. C006 is a learned positive exponential-sum approximation to a classical inverse integral. C006R is a resolvent/shifted solve. C007 is a kernel graph Laplacian. These identities are enough to withhold invention claims even though an exhaustive literature search is not complete.
